# AMP 接入设计决策（go2-wmp-him）

本文件是 2026-10-20 一轮 grilling 的结论记录，供 `/to-spec` 折叠成规格。它只记**决策与理由**，
不重复实现细节——实现细节在 `docs/AMP接入调研-byteDanceWMP与wmp_go1.md`（每条带 `path:line` 取证）。

## 背景

`go2_wmp_him` 的越障能力卡在三处：`gap 0.77` / `plum_blossom 0.013` / `single_beam 2.81`
（`logs/rsl_rl/go2_wmp_him_complex/2026-10-19_22-53-44`，5800 iter），策略表现为「腿先撞上去再反应」。
量化归因：每步回报里「脚越过障碍」相关的四项合计 **1.5%**，而「动作平滑省力」相关六项合计 **17.7%**
——优化器的结论是「不抬脚更划算」。参考实现（bytedance/WMP）的原始配方是 AMP + WMP 视觉 + 世界模型，
本文件决定往我们的移植版里补上 AMP 这一环。

## 两处前提更正（写在这里，避免后人重复踩）

1. **`reference_state_initialization` 在参考实现里出厂是 `False`**，配的 `prob=0.85` 是死键
   （`wmp_..._config.py`、`motion_loader.py` 均未读取）。它不是「参考实现靠它防爬行」的证据。
2. **AMP 在参考实现里只占约 1%**：`r_style = 0.01 * clamp(1 − (d−1)²/4, 0)`，纯加法并入任务奖励
   （`amp_discriminator.py:96-97`；`amp_task_reward_lerp` 只当 `>0` 开关，置 0 会连任务奖励一起丢，
   因为 runner 整体替换 `rewards`）。所以「照抄参考 = 得到强风格约束」是错的。

## 决策表

| # | 主题 | 决策 | 理由 |
|---|---|---|---|
| Q1 | 范围 | 判别器 + reference-state-init | 后者是可 A/B 的独立机制 |
| Q2 | 奖励集 | 按参考对齐，见下节 | 让这轮实验只检验「稠密风格先验」，不叠加手工 shaping |
| Q3 | 数据 | 仓库现成 `datasets/go2_motion/`（17 段） | 唯一零成本且已对齐 Go2 的方案 |
| Q4 | 风格集 | 只 trot 族（前/后/左/右/转/站） | hop/bound 会奖励「四脚同时离地」，与 5 cm 沟、0.5 m 石头冲突 |
| Q5 | 移植范围 | 先专做 Go2 | XZ1 的关节置换只在注释留位（`FL,FR,RL,RR` vs `FL,FR,RR,RL`）|
| Q6 | 奖励细节 | 见下节 | |
| Q7 | 训练起点 | 从零重训 S1（平地）→ S2 | 目标函数换血后热启动一个爬行策略会被判别器全判假 |
| Q8 | ref-init 落位 | 关节角/角速度、根线/角速度、yaw 取自片段；根高度 = 地形局部高度 + 0.32 | 片段 z 是平地高度，直接抄会埋进台阶 |
| Q9 | HIM | 保留 | 它是 actor 的 `base_lin_vel` 来源，这轮不做减法 |
| Q10 | 自录工具 | 本版不做 | 自录价值依赖策略已足够好，否则把缺陷固化进先验 |
| Q11 | 判别器观测 | 严格 30 维 `[dof_pos 12, base_lin_vel 3, base_ang_vel 3, dof_vel 12]`，绝对角、无噪声、无历史 | 加地形会让判别器把「站平地」当行为特征 |
| Q12 | `phase` | 从 actor 观测删除（47→45） | 它是已删的 `foot_gait` 的配套硬时钟，会与 AMP 学到的时序打架 |
| Q13 | reset 链 | 先原规则铺好，再按概率覆盖 | 保留清晰覆盖链，避免「哪些 env 走哪条路」变成隐式状态 |
| Q14 | 判别器预算 | 每 iter 1 次，batch 256（真:假 1:1），λ=10，`[1024,512]` MLP，线性输出，**独立 Adam** | 判别器最容易过拟合；共用优化器是参考实现的怪癖，不抄 |
| Q15 | 指标 | 照参考：`amp/loss`、`amp/grad_pen`、`amp/d_policy`、`amp/d_expert` | 另有既有的 `gait_*` 保留 |
| Q16 | ref-init 开关 | 实现，默认**关**，S1 上做 A/B（各 300 iter） | 出厂即关，先用 A/B 决定是否值得开 |
| Q17 | AMP 系数 | **0.15 全额**，不做地形衰减 | 要接替被删 shaping 的 5–15% 预算；0.01 在我们这里是 0.5% 噪声 |
| Q18 | 地形 | 只改列数与几何，`num_envs` 不动 | 列数是零代码风险的配置改动；env 数会同时扰动迭代时间与更新配比 |

## 奖励集（Q2/Q6 的精确形状）

保留：`tracking_lin_vel 1.5`、`tracking_ang_vel 0.5`、`joint_torques −1e-4`、`joint_acc −2.5e-7`、
`action_rate_l2 −0.03`、`lin_vel_z −1.0`、`dof_error −0.04`、`feet_air_time 0.5`（参考版单边
`clamp_min(0)`）、`leg_collision −1.0`、`feet_stumble −0.1`、`feet_edge −1.0`、
`joint_pos_limits −10`、`joint_velocity_limits −10`、`is_terminated −10`、`stand_still −0.5`。

删除：`foot_gait`、`foot_clearance_terrain`、`base_clearance`、`course_checkpoint`、
`body_orientation_l2`、`hip_pos`、`angular_momentum`、`body_ang_vel`、`foot_slip`、`soft_landing`、
`action_smoothness`；`pose` 被 `dof_error` 取代。

## 地形改动（Q18 的两条）

1. **赛道之间用虚空隔开**：新增 `WMP_TRACK_VOID = 0.40` 与共享构造函数 `_track_floor(body, size)`，
   地板只铺 `y ∈ [0.40, 7.60]`；8 个障碍族 + `omni_flat` 全部改用（`gap`/`plum`/`beam` 的分段板
   同样内缩 y 边界）。相邻赛道之间因此有 0.80 m 虚空。`forward_course_bounds.lateral_margin`
   0.20 → **0.60**（横向上限 3.8 → 3.4 m）。出生点 `(1.0, 4.0, 0)` 落在新可通行带正中，不改。
2. **轮胎间隙调小**：`WmpTireArrayTerrainCfg.pitch_range` `(1.15, 0.90)` → **`(0.98, 0.76)`**
   （相邻间隙 0.60/0.35 m → 0.43/0.21 m）。`tire_inner_diameter 0.33` 不变。

## 已知风险

- **AMP 0.15 全额 + 只有 trot 数据**，可能压制跨沟所需的非参考动作（这是 Q17 选 B 而非地形门控的代价）。
  缓解：观察 `gap`/`single_beam` 的 `progress/*` 是否反而下降；若下降，下一轮改成地形门控。
- **删掉 `foot_clearance` 后，抬脚高度只由 `dof_error` 与 AMP 间接约束**，没有直接观测量。
  缓解：`gait_*` 指标保留；必要时新增「摆动相足端峰值高度」指标再评估。
- **参考实现的 checkpoint 不存判别器与归一化器**，续训会静默劣化。我们按正确方式实现（两者都存），
  并且归一化器统计用**归一化之前**的数据更新（参考实现的 bug 不抄）。
- 片段帧关节序 `FL,FR,RL,RR` 与 Go2 MJCF 一致，**不要加任何置换**（A1/Go1 才需要左右对调）。

## 验收（S1 平地，300–500 iter）

- `amp/d_policy` 与 `amp/d_expert` 都不贴 0 或 1（判别器仍有分辨力）。
- `gait_diagonal_match ≥ 0.70`（不比上一轮 S1 的 0.73 差）。
- `mean_std ≤ 0.70`。
- `mean_episode_length` 在 300 iter 内 ≥ 900。
- ref-init A/B：开/关两种设置的 `gait_hind_swing_ratio` 与 `mean_episode_length` 差异。
