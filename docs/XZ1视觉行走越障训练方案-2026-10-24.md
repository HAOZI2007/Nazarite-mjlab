# XZ1 视觉行走越障训练方案

评估日期：2026-10-24。依据本地代码、各次实验保存的参数、TensorBoard 事件和三个参考仓库。
本文是待实施的训练方案；没有修改训练代码或启动新训练。日志数值为读取时快照。

## 1. 推荐决策

主线采用 **XZ1 HIM 基础行走 → 特权地形教师 → WMP 世界模型预训练 → 深度视觉学生蒸馏 → 小步 PPO 微调 → 独立部署验证**。

最终学生保留 HIM、深度 CNN 和 RSSM World Model。教师阶段增加可以直接读取地形的 actor 分支，让越障动作先学出来，再让视觉学生在自己的状态分布上模仿。
AMP 作为有 XZ1 合格数据之后的可选运动风格正则，第一版默认关闭。

这不是原 WMP 的原样复现，而是以现有 XZ1 基础策略为起点，结合 Extreme Parkour 教师学生流程和 WMP 时序感知的工程方案。
不建议再次同时从零训练基础步态、视觉、世界模型、运动判别器和全部障碍。

## 2. 现有训练给出的证据

统计口径：每条曲线最后 100 个 scalar 记录的均值；不是 100 个固定测试回合。不同实验改变过奖励、地形与晋级规则，不能据此计算算法的受控提升率。
episode length 单位为策略步，当前控制频率 50 Hz，20 s 对应约 1000 步。

Go2 flat 的 `2026-10-19_14-19-25` 无 AMP，末段回合长约 994 步、机身离地约 0.328 m、倾角约 0.058 rad。
它说明“没有 AMP 就完全学不会平地行走”不成立；它没有证明无 AMP 已能完成精确落脚越障。

Go2 10 月 21 日实验的世界模型 image loss 约 0.0172，AMP 专家/策略分数约 +0.851/−0.856、实际平均 style reward 约 0.00310/策略步。
这些指标说明模块在运行，并不证明视觉真正改善越障，也不证明 AMP 已学出专家动作。

XZ1 最新日志接近完整回合，可以列为热启动候选；后腿负载指标偏高，应检查力矩饱和持续时间、速度和目标跟踪误差。
0.79 这个指标本身不能等同于“79% 时间饱和”。XZ1 地形类型会自适应重采样，类型等级的接近也不等于各类障碍同样熟练。

当前 `Metrics/twist/error_vel_xy` 按指令重采样窗口累计归一化，不能直接当作独立评估中的逐步速度 MAE。
现有部分 termination scalar 大于 1，也不能直接解释为失败百分比。最终验收应另外逐回合计数。

## 3. 三个参考仓库分别借什么

| 来源 | 可以借鉴 | 本方案的处理 |
| --- | --- | --- |
| `wmp_go1-main` | 深度 CNN、RSSM、低频相机与动作分块、序列训练、端到端部署封装、AMP 接口 | 保留时序感知主干；重新适配 XZ1 动作与数据；增加教师监督 |
| `extreme-parkour-main` | 特权扫描策略先学会越障，再训练深度学生；学生执行动作、教师在线提供标签 | 作为训练流程主线 |
| `AME_Locomotion-main` | CNN 地形编码、本体查询与地形特征注意力融合 | 作为教师地形编码的后续对照，首版先用简单编码器 |

Extreme Parkour 当前 `learn_vision()` 的实际启用路径主要监督动作和 yaw；单独地形 latent loss 的调用被注释。
因此下面提出的 latent 对齐是本项目增加的辅助项，不能称为照搬其默认实现。

本地 AME 是 G1 29DoF、高程图输入版本，不是已经验证的 XZ1 深度策略。两个非 WMP 参考实现的主线均不依赖 AMP。
本方案不复制 G1 的双足步态和关节奖励。

## 4. 开训前必须完成的数据与模型检查

### 4.1 XZ1 模型和动作合同

- 固定关节、足端顺序为 `FL, FR, RR, RL`，每腿 hip/thigh/shank。现有 Go2 AMP 数据顺序为 `FL, FR, RL, RR`，不能原样输入。
- 保留 XZ1 自己的关节符号、零位、轴向、限位、站姿补偿和动作尺度，不能只换 Go2 XML。
- 当前配置为名义站高 0.30 m、动作尺度 0.25 rad/action、力矩限制 31.7 N·m、2 ms 物理步与 20 ms 控制步。均作为仿真假设复核，不把它们当作已测得的硬件能力。
- 先验证零动作静站、前后侧向移动、转向、reset 落地和脚掌接触位置。记录目标角与实际角、力矩、关节速度和接触穿透。
- 相机和机载计算机的质量、COM、外形也应进入最终模型。部署延迟按实测设置。

### 4.2 已复现的 WMP 回合边界问题

`rl/wmp/runner.py` 每个策略步执行 `_wm_is_first.copy_(dones.float())`，但世界模型只在每 5 步分块结束时消费此标志。
若 reset 发生于块内，后续非 reset 步可在消费前把标志覆盖为 False。
用现有 CPU 测试桩复现：第 2 步 reset、第 5 步更新，replay 中标志为 `[False, False]`，应保留的第一环境 reset 为 True。

实施时需逐环境锁存 pending reset，直到相应世界模型更新真正消费；同时清除该环境旧 RSSM 状态、缓存 feature、动作历史和历史观测。
覆盖分块内所有 reset 相位、异步多环境 reset 和 play 路径。不能只清零动作而保留旧回合记忆。

### 4.3 其他必须核对的接口

- AMP 当前虽不使用跨 reset 的样本训练判别器，但计算奖励仍读取自动 reset 后的观测；若采用 AMP，必须使用 terminal observation 或屏蔽无效风格奖励。
- World Model 的 33 维 prop 应按命名字段组装，避免把 Go2 的 48 维 estimator 切片写死到 XZ1 的 50 维布局。
- prop 只含部署可取得的本体量。训练、play、导出在噪声、延迟、缩放上遵守同一合同，不能在部署依赖 `estimator` 这个训练环境对象。
- 固定相机的深度定义：轴向 z-depth 或射线距离、单位米、裁剪范围、长宽比、裁剪与缩放、无效像素处理。内外参采用 XZ1 实际安装参数。
- 当前与参考代码的 CNN 都在已中心化图像后再次减 0.5。这是参考编码约定，不能仅凭“又减了 0.5”认定重复归一化并单独改 play；任何改变都要同时改训练与部署并重新验证。
- `kl_free` 是 KL 下限。`kl_dyn_rep` 接近 2 不足以认定动力学完全失效，应同时记录未截断 KL、活跃潜变量和预测表现。

## 5. 第一版网络设计

### 5.1 保留 XZ1 的 47 维本体定义

单帧本体：角速度 3 + 重力投影 3 + 指令 3 + 相位 2 + 关节角误差 12 + 关节速度 12 + 上一动作 12 = 47。
HIM 使用 6 帧历史，估计速度 3 维和 latent 16 维。当前相位与基础 gait reward 先保留，越障时逐渐减弱固定节律约束。
不为兼容 Go2 最新的 45 维 AMP actor 而删除 XZ1 相位；第一版 AMP 关闭，避免不必要的接口变更。

### 5.2 教师

教师 actor 输入为 `47 + HIM速度3 + HIM latent16 + 地形latent32 = 98维`。
新增 actor 地形编码器；目前 XZ1-HIM 的 height scan 只在 critic，不能直接当作已有视觉教师。

先使用小型 CNN/MLP 将局部扫描编码成 32 维。建议扫描前移，例如 x∈[−0.4,1.6] m、y∈[−0.6,0.6] m、分辨率 0.1 m，形成 21×13 网格。
扫描范围应与相机可见区域、控制速度和记忆长度共同校准。
限高框架另需前向/上方距离或净空扫描：仅向下高程图不能充分描述头顶横梁与可通行空间。

critic 使用干净本体、真实速度、接触、地形等特权量；明确与 actor 分开。
障碍类型 ID 可用于配置奖励/课程，第一版不送入 actor，避免学生依赖实机没有的标签。

### 5.3 视觉学生

深度图 64×64 → WMP CNN；本体 prop 33维 → MLP；最近 5 个 12维动作折成 60维 → RSSM。
RSSM 确定性状态 512维 → 视觉投影32维；学生 actor 同样接收98维输入，输出12个位置目标残差。
策略50Hz，相机/世界模型先用10Hz；新图像之间保持视觉特征，本体和HIM仍每20ms更新。
部署按“新帧+时间戳”驱动，并处理丢帧，不能假定真实相机永远严格每5步到帧。

教师和学生用相同本体/HIM/actor接口，分别提供32维地形表示。采用动作监督作为主要蒸馏目标，latent对齐作为可调辅助项。
基础 checkpoint 扩展输入时，保留原本体网络列并将新增视觉列初始化为零或小值；随后必须确认策略确实学会使用视觉。

World Model 在这里提供时序感知和障碍记忆。第一版不引入 imagined rollout、MPC 或世界模型内 PPO，以控制实现范围。

## 6. 分阶段训练与验收

以下迭代预算仅用于安排实验；达到验收门槛才进入下一阶段。新任务名称为建议，尚未注册，不能直接作为启动命令使用。

| 阶段 | 内容 | 初始预算 | 进入下一阶段的条件 |
| --- | --- | --- | --- |
| P0 模型与接口 | 上述接触、reset、时序和观测检查；导出最小 recurrent 推理样例 | 小规模检查 | 数据链路一致；零动作静站稳定；无跨回合记忆 |
| P1 基础行走 | 评测现有XZ1-HIM候选，必要时在平地/低起伏热启动 | 0–3000 iter | 固定速度网格上稳定走、停、转；无拖腿/腹部承重 |
| P2 特权教师 | 加actor地形分支，先易地形，再加入精确落脚与限高 | 5000–15000 iter | 每类中等难度100回合通过率≥85%，目标尺寸≥70%再进入学生实验 |
| P3 WM预训练 | 采集教师与早期学生轨迹；离线/独立序列训练 | 先采0.5–2小时模拟时间/地形族 | held-out序列优于简单预测基线，特征有限，reset正确，有效落脚信息可解码 |
| P4 深度蒸馏 | 冻结教师，学生执行并在线查询教师标签 | 3000–8000 iter | 相同测试集成功率达到教师的≥90%，关键类不能被总体均值掩盖 |
| P5 PPO微调 | 低学习率，保留教师约束，增加视觉/动力学随机化 | 2000–5000 iter | 固定测试≥85%，实际目标赛道整段≥80%；能力无明显退化 |
| P6 部署验证 | 独立MuJoCo回放与实机递进测试 | 按实测问题迭代 | 导出与训练输出一致、时延达标、实际障碍通过率达标 |

这些百分比是项目建议门槛，不是已达到的结果。目标尺寸是否具备运动学、力矩与稳定性余量需先测试，尤其是高墙、窄桥和大gap。

P1固定网格建议覆盖 vx=0/0.2/0.4/0.6 m/s，侧向±0.2 m/s，yaw±0.4 rad/s，另测倒退与原地停。
在指令稳定段独立计算逐步线速度MAE，先争取≤0.15–0.20 m/s，正常平地20s回合完成率≥95%。
现有XZ1策略通过这些门槛就直接复用，不再无条件从零训练一轮。

P3数据要包含成功越障、接近障碍、失败恢复、转向、视野离开后的落脚，以及少量学生偏离教师轨迹的状态。
序列应保留时间戳、深度、可观测本体、实际执行动作、reset/terminal标志和教师标签；按赛道seed分训练/验证集。
不能主要拿平地数据预训练，再期待图像重建模型自动学会识别稀疏落脚点。

P4损失建议从 `action_loss + 0.1*latent_loss` 开始，并行观察两者梯度；若尺度不相称先归一化。
开始允许教师/学生混合执行，逐渐过渡到学生执行、教师只标注；后者是覆盖学生自身失败状态的关键。
WM预训练后先冻结主干，训练视觉投影和学生actor；若冻结特征无法提供必要地形信息，再以较低学习率联合微调WM并加入任务辅助监督。

## 7. 地形与课程重新组织

保留现有八类障碍：上下楼梯合并、实心梯形斜坡、限高框架、高墙、梅花桩、gap、轮胎阵列、单块独木桥；另保留平地全向练习区。
训练场强调密度、可恢复失败和几何随机化；比赛尺寸与组合在独立评估场固定，不能只用随机训练地形验收。
最终尺寸需按当前有效规则再次核对，不能把Go2训练配置的0.42m墙高当作XZ1或比赛要求。

| 能力组 | 容易起点建议 | 后续推进 |
| --- | --- | --- |
| 楼梯/斜坡/起伏 | 阶高3–5cm，坡8–10°，充足起步与顶端/末端平台 | 逐步增高增陡，再增加转向和组合 |
| 高墙/轮胎 | 墙5–8cm；轮胎先少量、稀疏排列并保留真实环形几何 | 调整高度/密度，最终使用目标规则尺寸 |
| gap | 缝宽2–5cm，坑较浅或有防坠底，落台足够长 | 先扩大缝，再缩短落台/增加连续缝，最后达到目标坑深 |
| 梅花桩 | 顶面与起步平台齐平，间隙2–5cm、宽大落脚面 | 逐步缩小桩面、增大间隙并随机错位；不同时骤增所有参数 |
| 独木桥 | 单块桥面宽≥XZ1实际站立足端宽+约15cm余量 | 逐渐缩窄，测试不同入桥偏移和朝向 |
| 限高框架 | 高于XZ1实际最高点，先不要求蹲伏 | 逐渐降低净空，联合训练降低姿态与恢复站高 |

出生点保证整机和脚掌落在平地安全区域，离第一个障碍留出约1–1.5m预览/加速空间，按整机包围盒检测reset是否合法。
每块地形放2–4个可通过障碍，以有效遭遇次数而非单纯密度优化；不可把过密且无助跑/恢复的平台误当课程。
不恢复分隔墙走廊；采用开放地块、足够宽的障碍横向覆盖和虚拟越界/检查点规则，防止绕过障碍。

晋级基于最后有效障碍之后的检查点，而非固定“相对origin走4m”。当前WMP的8m地块有障碍位于x=6.55m，出生参考x=1m，走4m可能尚未经过最后障碍。
梅花桩/桥/gap还要核验有效支撑、脚未踏坑底和机体未沿边绕行；根位置通过平面不是全部足端通过。
成功后须进入稳定落地区；非任务允许的机体承重、掉坑、绕行不能算成功。

建议每类独立成功率EMA、连续2次成功晋级/连续3次失败降级作为起点，并始终保留20%–30%简单地形复习。
自适应分配增加弱项采样，同时给每类设置最低采样份额，避免最弱项占满训练或被完全放弃。

前向路线采用正vx和目标航向纠偏，速度初期0.2–0.5m/s；视觉精确落脚允许障碍前减速。
楼梯/坡上的全向训练只在四周有合理承接的独立地形中使用，晋级用相应方向目标；不要把全向指令配上只认+x的晋级。
全向平地/宽缓坡练习应始终保留，避免越障续训后忘记侧移、转向与停步。

## 8. 奖励设计原则与起始参数

第一版沿用XZ1现有奖励接口作为基础，增加任务成功与安全落脚信号，不同时照搬三套奖励。

- 速度跟踪权重先保留1.5；角速度0.5–0.8。障碍附近允许短暂减速，避免撞墙比安全越障更赚钱。
- 增加沿路线的有界progress shaping和一次性检查点/完整通过奖励，防止反复跨同一平面刷分。记录成功奖励相对跟踪奖励的实际幅度。
- 平地保留轻量对角步态；跨墙/连续落脚/限高期间放宽固定相位，不用固定0.6s相位匹配作为所有地形的硬晋级门槛。
- 抬腿用相对局部障碍的摆动期净空，并给容忍区间；不要要求支撑脚离地。当前XZ1 `target_height=0.25m` 不宜无差别用于平地，先对照0.08–0.12m平地目标，越障按障碍顶面额外留约0.03–0.06m余量。
- 平地约束机身水平；斜坡、楼梯允许任务所需pitch；限高放宽站高；高墙允许短时竖直速度。不能通过统一放宽所有姿态来放行腹部爬行。
- 持续腹部承重和持续拖腿保留惩罚/终止，短暂合法擦碰采用持续时间与受力方向判断。
- action rate、action acceleration、能量惩罚先用XZ1当前量级，不再叠加多个相近光滑项后大幅提高。越障阶段若正则压过成功信号，逐项减弱并做对照。

首轮每项都记录加权后每秒/每回合贡献、非零触发率和地形分组统计。不能只根据weight大小判断哪个项主导。

AMP若后续加入：先用通过P1评测的XZ1策略采集站立、多速前后左右和转向片段；没有合格策略时，采集工具不会凭空生成合格动作。
也可重定向外部动作，但必须做XZ1逆运动学、碰撞、关节符号和动力学可执行性检查，仅换腿序不足够。
输出61维容器、提取30维AMP状态，按实际采样间隔插值/重采样；处理非循环片段尾部和跨reset样本。
风格强度依据实际 style/task reward 比例调节，先温和使用，必要时在非平地动态动作上减弱，避免平地trot先验压制越障。
判别器仅训练需要，部署不需要；HIM是状态估计器，与AMP运动先验作用不同，两者可以共存。

## 9. 初始训练参数和算力预算

P1/P2先使用800–1024环境、64或100步rollout、50Hz控制；保持2ms物理步，先不同时改物理精度。
P2从P1热启动，学习率从1e-4–3e-4试起，熵系数0.003–0.01；记录实际KL/学习率，避免把Go2的硬学习率下限当通用解法。

视觉阶段先以256–512环境核验显存/吞吐，再决定是否扩展；控制任务容量和障碍密度一致，比较每秒有效越障遭遇次数。
WM从batch16、序列32起步，稳定后增到64；10Hz下64帧已是6.4s，早期短失败回合未必能提供合法序列。
warmup判断应包含合法连续序列数量，而非只看总帧数。
在线联合阶段先用每迭代1–3次WM更新，依据held-out预测、学生成功率与耗时再增加，避免因重建loss好看而堆更新次数。

当前Go2 10月21日末段每64步rollout，采集约5.14s、学习约4.83s，总约9.97s/iter。
按这一已测吞吐，5000次迭代约13.8h，10000次约27.7h；这是该Go2实验的预算换算，不是XZ1教师/学生的耗时预测。
教师阶段无需渲染深度；WM预训练和蒸馏按各自吞吐计量。Extreme Parkour README的3090时间也不能直接套到本机。

每500iter进行一次固定验证；前100/500/1000iter优先排查姿态、动作/力矩、接触和视觉有效性。
任一能力连续两次评测明显退化，保留checkpoint并定位原因，不自动用“继续训练更久”替代排查。

## 10. 证明视觉和世界模型有效

固定未参与训练的地形seed，每类至少100回合，报告成功率、95%置信区间、完成时间、复位次数、踏空/边缘接触和持续腹部/腿部接触。
训练曲线中的terrain level和distance只作为诊断，不作为最终验收。

至少保留以下对照：

1. 当前XZ1盲HIM；
2. 特权地形教师；
3. HIM+深度CNN/GRU学生，作为时序视觉的轻量基线；
4. HIM+WMP RSSM学生，作为主候选。

每个候选在相同预算、奖励与固定赛道下比较；最终主要候选使用至少3个seed。
评测学生的正常深度、重复旧帧、错配其他环境深度和关闭视觉分支；短时遮挡另作鲁棒性测试。
这些干预会造成分布变化，性能下降可证明输入敏感性，但不能单独证明视觉理解正确；要结合准确深度相对盲策略的收益和可解释的落脚/抬腿时机。
若WMP不能超过或匹配轻量基线，应先修特征/时序，必要时用轻量视觉版本备赛，保留WMP研究分支。

## 11. 部署与实施顺序

现有WMP runner明确没有完整ONNX导出。参考仓库已有组合World Model与actor的TorchScript导出，可借鉴封装方式，不能直接使用其Go1模型。
部署模块必须包含深度预处理合同、HIM历史、RSSM状态、动作历史、归一化统计和reset接口；训练用decoder、critic、AMP判别器不必部署。
建议显式状态输入输出的TorchScript或ONNX子模块，保证可测试、可恢复，不把内部环境对象带到机器人上。
在目标计算机上分别测50Hz actor和10Hz视觉更新的p50/p95时延；满足控制期限且保留余量再上机。
相机掉帧按训练覆盖的短时复用处理，长期失效触发明确的降速/停止行为，不能无限沿用陈旧地形记忆。

实施顺序：

1. 修复/验证WMP异步reset、深度与动作分块合同，冻结XZ1资产版本。
2. 新增独立XZ1基础/教师/视觉任务，复用算法模块但不让XZ1继承Go2机器人与奖励配置。
3. 建立真正按障碍完成度计数的评测器和课程元数据。
4. 加actor地形编码器并用现有XZ1-HIM热启动教师；评测后选择checkpoint。
5. 建立教师数据采集、WM预训练和学生在线动作监督流程。
6. 在小任务上打通导出等价性，再扩到全部障碍、随机化和整段赛道。
7. 只有基础步态确实成为瓶颈时，才加入合格XZ1数据驱动的AMP对照。

主要改动入口：

- `Train/Nazarite/Nazarite-src/nazarite/config/train_config/XZ1_env_cfgs/`：独立环境、地形、观测与runner配置。
- `Train/Nazarite/Nazarite-src/nazarite/rl/wmp/`：可复用WM、序列buffer、actor；新增教师/学生训练与导出接口。
- `Train/Nazarite/Nazarite-src/nazarite/mdp/`：具名本体观测、路线检查点、地形条件奖励和课程。
- `Train/Nazarite/Nazarite-src/nazarite/__init__.py`：新增任务注册；保护现有Go2任务。
- 对应CPU时序/观测测试、小环境传感器与reset检查、固定赛道评测与导出一致性测试。

新增教师与DAgger/动作蒸馏属于中等规模算法工程，绝非只换XML和cfg。以现有基础估计：首个能训练/评测的闭环约1–2周开发调试量级，稳定仿真与部署验证需额外时间；取决于基础策略、算力、相机和实机条件，不作成功日期保证。
