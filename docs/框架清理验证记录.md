## 独立 GPU 冒烟与原有故障

另外在 2 个环境、零动作、3 个控制步条件下检查了下列任务。对照组从 Git
原始源码单独运行，训练包与 mjlab 源码均来自修改前版本，机器人资源只读复用。

| 任务 | 修改前 | 修改后 |
|---|---|---|
| `Nazarite-Velocity-Flat-Go2` | 通过 | 通过 |
| `Nazarite-Velocity-Flat-Go2-WTW` | 通过 | 通过 |
| `Nazarite-FRNet-Recovery-Terrain-Go2` | 通过 | 通过 |
| `Nazarite-FRNet-Recovery-Go2` | 缺少高度图传感器 | 同样报错 |
| `Nazarite-Velocity-Flat-XZ1-WTW` | calf/shank 关节匹配失败 | 同样报错 |

两处原有故障的具体原因：

1. 平地 FR-Net 默认 `use_critic_height_map=True`，critic 读取
   `frnet_terrain_height_map`，但该传感器仅在复杂地形分支安装。
2. XZ1 WTW 使用 `.*(FR|FL|RR|RL)_calf_joint.*`，XZ1 MJCF 的对应关节名是
   `*_shank_joint`。

本次保持两处任务配置不变，未夹带调参与行为修复。因此可以确认本次清理和
目录迁移没有引入这些故障，但不能将上述两项宣称为已正常启动。
