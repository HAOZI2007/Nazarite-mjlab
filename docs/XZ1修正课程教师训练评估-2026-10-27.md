# XZ1 修正课程后的教师训练评估

分析对象：`Train/Nazarite/logs/rsl_rl/xz1_wmp_him_teacher/2026-10-27_17-48-42_stage2_fixed_curriculum/`，最终模型 `model_2499.pt`。

结论：课程修复后的训练取得了实质进展，之前失败的最高限高框架和中高难度 gap 已在独立评测中通过；没有复现上一轮的非有限恢复。但是模型存在低难度梅花桩退化和高墙速度敏感问题，尚不适合作为完整九地形最终教师启动正式数据采集。建议下一步优先恢复课程的难度覆盖，再补齐速度覆盖，暂不统一增大抬腿奖励或放宽终止。

本轮只读取训练数据、运行短时推理评测并保存报告，没有修改训练代码、奖励、地形和 checkpoint，也没有启动训练。

## 训练范围与健康度

本轮完成迭代 0–2499：800 环境、每次 100 步，共 2 亿环境步。配置确认从上一轮 `model_1600.pt` 权重热启动，`resume=False`；固定地形类型，初始等级为 0，使用版本 2 课程契约。

| --- | ---: | ---: |
| 平均回报 | 7.94 | 15.08 |
| 平均回合步数 | 317 | 422 |
| Value loss | 0.1084 | 0.0198 |
| HIM estimation loss | 0.0348 | 0.0224 |
| 动作分布标准差 | 0.467 | 0.422 |

后 100 次平面速度误差约 0.172m/s。曲线没有全局发散迹象。当前与上一轮的课程、类型分布、回合结束构成不同，不宜用两轮总回报大小直接比较越障能力。

检查了全部 470 个 TensorBoard 标量序列，没有非有限记录；`nan_recoveries` 全程为 0。抽查 `model_0/500/1000/1500/2000/2499.pt` 的模型及优化器张量，全部有限。训练目录没有非有限恢复现场文件，符合本轮未触发恢复的记录；不能据此证明潜在数值问题已永久消失，也不能单独归因于课程修复。

动作裁剪仍需关注：后 100 次动作元素裁剪占比约 0.00484%，每次 rollout 的原始动作最大值均值约 147.7。大动作很少，但不能将“没有 NaN”等价为所有状态和动作都温和。

## 剩余问题与现场核对

1. **低难度梅花桩真实踩地。** 低难度桩高 5cm，名义评测 0/4，扰动 0/16；单环境 0.4m/s 在 3.00s、前进约 1.21m 时触发 `obstacle_ground_contact`。现场两只脚相对桩面高度约 -3.18cm、-2.61cm，垂直承重力绝对值约 115N、29N，满足当前的双脚踩地判定。不是单纯的姿态终止。提高到 0.6m/s 的单回合仍在 2.34s 踩地失败。当前成功主要集中在最高级，与低等级覆盖不足、遗忘相符；尚未做课程消融，不能把原因完全归结为这一项。
2. **最高高墙对速度敏感。** 30cm 高墙、0.4m/s 的名义 4 回合均超时，根位置停在出生点前方约 1.66m，前脚靠近墙前，没有越过。单环境将速度改为 0.7m/s 后，4.16s 通过；这证明有该条件下的过墙能力，不证明慢速也能通过。训练命令每 8–12s 重采样，并有 heading 纠偏，而固定速度评测持续保持 0.4m/s；训练成功率高不保证固定慢速通过，具体贡献尚未隔离。
3. **轮胎中间难度有停滞样本。** 难度 0.5 名义 3/4，一例 20s 超时、根位置约 1.13m；另一个单环境复查可在 11.96s 通过，说明该条件下结果尚不稳定。最高难度的好结果不能代替对中间难度的验收。
4. **gap 与独木桥在随机训练条件下仍有余量。** 虽然本轮名义和起点扰动评测通过，训练末段 gap 仍约 20% 失败、桥约 11% 失败；这些样本不应因为小规模名义测试全通过而被忽略。

## 下一步建议

优先调整课程的难度覆盖。当前所有窄障碍均被归为 sparse，最高级通过后一直保留最高级，缺少回到低中等级的复习。WMP 原参考 `legged_gym/envs/base/legged_robot.py:956` 明确将通过最高级的机器人重新分配到随机等级。建议沿用该行为，同时保留本次修正的固定类型和按类型连续计数，不再跨类型借等级。

之后以当前权重做针对性训练和验收，重点看最低梅花桩、最高墙的 0.3–0.7m/s 固定速度区间、中等轮胎；同时保留已学会的框架、gap 和桥。课程覆盖修改与奖励改动分开验证，先不要统一增加抬腿、降低姿态惩罚或放宽踩地终止。高墙速度表和轮胎复查是验收目标，当前结果不足以直接指定新的奖励权重。

在这批缺口修复并通过随机条件验收后，再重新采集覆盖九类、低中高难度以及所需速度范围的教师深度序列，更新 WMP 世界模型并蒸馏视觉学生。当前模型可以保留作为候选教师和对照，不建议立刻作为唯一教师启动正式大规模采集。
