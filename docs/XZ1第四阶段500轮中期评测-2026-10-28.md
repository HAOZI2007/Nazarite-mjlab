## 结论

训练数值正常，课程回采覆盖到八类障碍的全部 10 级；当前教师在名义条件下
保留了梅花桩、最高级独木桥、窄坡和限高框架的通过能力。
但不能认为 gap 弱项已经解决：相同 CPU 条件下，旧教师 gap 第 1 级为
15/16，当前为 13/16。最高级高墙在 0.3 m/s 下也只有 13/16。
这些是单种子、小样本结果，不能单独证明普遍退化或显著提升。

建议让现有训练继续到 1000–1500 次更新再验收，保留旧教师及当前快照，
暂不根据本次中期结果修改奖励、学习率或课程。还不宜将本模型作为已完成验收
的唯一教师立即开始正式大规模 WM/学生数据采集。

## 独立仿真评测

由于当时 GPU 仅余约 580 MiB 显存，为避免挤占训练显存，本次使用 CPU Warp
仿真，actor 和 HIM 推理也在 CPU。CPU checkpoint 副本与原文件的 actor、critic、
估计器全部张量逐项核对完全相等；副本仅改变存储设备，不改变网络权重。
原 checkpoint 的 SHA256 和核对结果保存在 `evaluation_summary.json`。

两位教师统一使用本次修正后的真实坑底失败条件。每组 16 个环境各完成首回合，
不因快失败重采而截掉慢成功。seed 43；出生扰动 x±0.10 m、y±0.05 m、
yaw±0.05 rad；`course` 真值中心线纠偏；关闭物理随机化、观测噪声和延迟。
除高墙采用 0.3 m/s 外，其余速度均为 0.4 m/s。
成功要求完整越障、足端落地和 0.2 秒稳定窗口，失败优先。

| 测试 | stage3 model_1499 | stage4 model_500 | 当前失败 |
| --- | ---: | ---: | --- |
| gap，第 1 级 | 15/16 | 13/16 | 3 次真实坑底接触 |
| 梅花桩，第 0 级 | 15/16 | 16/16 | 无 |
| 独木桥，第 9 级 | 16/16 | 16/16 | 无 |
| 窄坡，第 9 级 | 16/16 | 16/16 | 无 |
| 限高框架，第 9 级 | 本次未重测 | 16/16 | 无 |
| 高墙，第 9 级、0.3 m/s | 本次未重测 | 13/16 | 3 次超时 |

合计 10 组、160 个完整回合，其中当前教师 96 回合、旧教师 64 回合。
这是重点地形验收，不是九类 × 十等级 × 多速度/多种子的完整矩阵。
CPU 与 GPU 轨迹会有数值差异；例如旧教师同类 gap 测试此前在 GPU 为 12/16，
本次 CPU 为 15/16，不能将跨后端成绩混用来宣称进步。

最高墙的三个超时环境编号为 3、8、12，20 秒后躯干前进分别约
1.671、1.687、1.668 m；墙中心距出生点约 2.0 m，三个样本的
`crossed_obstacle=False`，稳定落地累计最高为 0 秒。
这些样本没有完成越墙，不是越墙后因落地窗口漏计；尚未凭轨迹动画确认具体
卡住姿态，不能据此直接归因于姿态奖励或抬腿奖励。

当前桥/坡的名义评测全部通过，与训练最高级仍只有 83.5%/87.7% 并不矛盾：
评测关闭了物理随机化与噪声，使用固定速度及出生扰动，训练条件更广。
本次评估对象是读取特权高度扫描的教师，不代表深度视觉学生已完成验收。

## 后续建议

1. 继续当前训练，到 1000 次更新复查；若仍在进步，再完成原定 1500 次预算。
   暂不因第 500 轮的小样本结果重启训练或改整套奖励。
2. 下次优先复测 gap 第 1/2 级、低难度梅花桩、低速最高墙，增加种子与速度。
   同时检查独木桥、窄坡最高级在训练扰动下的统计，避免只看到名义全通过。
3. 若训练末段上述薄弱项仍停滞，先采集失败前后的扫描、足端轨迹、动作及
   接触时序，再决定感知、奖励或课程的修改，不仅依据平均回报调参。
4. 正式采集九类教师数据前，补齐所需等级和速度的验收；GPU 空闲时应在
   CUDA 上把旧/新 checkpoint 都按相同条件复测，建立同后端基线。
