# XZ1 WM 续训5000次评估（2026-10-27）

实验目录：`Train/Nazarite/logs/wmp_pretrain/xz1_wm_v1_resume5000/`。

结论：建议保留 `wm_5000.pt`，进入第一版深度视觉学生蒸馏的实现和小规模闭环验证。WM具备可用于启动蒸馏的视觉地形信息；当前不应宣称学生越障或部署已验收。无需把继续增加纯WM训练轮数作为下一阶段的前置条件，先检验这些特征能否转化为教师动作和实际越障表现。

本次只读分析日志、加载权重做GPU推理和诊断probe，没有更新WM，没有启动训练，没有修改训练源码。

5000次是已有保存点中验证总损失和总体未来误差比最好的版本。2500次时总体比值已降至0.938，4500次为0.683，5000次仍有改善。

最后100次训练图像损失均值1.837，对应最终验证1.470；本体训练均值0.735，验证0.853。未出现明显严重过拟合。不能用第5000次单批训练总损失2.266直接与16批验证均值4.787比较来断言过拟合。

本轮梯度范数最大610.23，低于参考裁剪阈值1000；最后100次平均51.89。未发现明显梯度爆炸。奖励重建损失约5.541保持不变，是参考配置奖励头loss scale=0的预期行为。

## 是否真正使用视觉和动作

在同一组84条窗口、20帧上下文下：

| 输入设置 | 未来图像MSE |
| --- | ---: |
| 正常深度与动作 | 0.002596 |
| 深度全部替换为远裁剪值 | 0.069429 |
| 正常观测，未来动作置零 | 0.006876 |

遮掉深度后误差约为正常的26.7倍；将未来动作置零后约为2.65倍。说明模型预测会使用深度和动作。全远深度、动作置零都是人为改变输入分布，不能直接视为真实传感器故障概率或因果能力验收。

## 512维deter是否能表达教师地形标签

直接针对未来学生实际使用的512维deter做额外诊断。训练、验证各84条均衡窗口，分别使用种子42–45和46。每窗口跳过前5帧，共4956帧/集合；在线性ridge探针中拟合教师32维地形标签，只更新临时探针，不更新WM。所有探针均使用各自训练集标准化，正则系数1。

| 特征 | 验证标签MSE |
| --- | ---: |
| 训练标签均值 | 0.10060 |
| 当前本体prop33 | 0.06487 |
| 正常视觉WM deter512 | 0.03422 |
| 遮掉深度后的WM deter512 | 0.05275 |

正常WM特征比prop线性探针误差低约47.2%，比无深度WM探针低约35.1%。窄坡正常WM标签误差0.01343，窄楼梯0.02030；对应prop为0.09374和0.11127。这支持先以现有512维状态启动视觉投影和动作蒸馏。

探针维度、时序上下文不同，且覆盖的仍是教师轨迹；不能将此结论推广为学生已经能控制。金字塔楼梯的WM线性探针0.07157，略差于prop探针0.06295，仍需在学生验证中特别关注。

## 图像质量与下一阶段

抽查中等难度窗口：相较1000次模型，地面重建更平滑准确，窄坡和窄楼梯的轮廓开始恢复；阶沿、随机台阶块体细节仍偏模糊。当前后验重建与未来0.5秒预测都存在该现象。较好的平均像素误差不是足部精确落点的充分条件。

不过，现有结果已提供三项推进依据：未见明显数值/时序故障；held-out未来预测优于基线；供策略使用的512维状态中可解码出教师地形信息。可以进入学生试验，把主要验收从图像重建转为动作监督和实际越障，而非继续单靠图像清晰度决定全部进度。

建议下一批实现沿用既定主线：

1. 冻结教师及 `wm_5000.pt` 主干，教师继续读取132维真值扫描，只提供监督标签。
2. 学生从同一教师初始化HIM和actor，用WMP的512维deter经视觉投影得到32维表示，替代教师扫描latent；actor输入仍为 `47+3+16+32=98` 维，输出12维动作。
3. 主要训练视觉投影和学生actor，动作监督为主。在线查询教师标签，逐步覆盖学生自己执行时的状态；不能仅以教师离线数据的动作误差作为闭环验收。
4. 固定地形/难度评测，分别比较教师、正常深度学生、错配深度或失效视觉学生。特别关注窄坡、窄楼梯和金字塔楼梯，并区分普通速度指令与特权赛道纠偏。
5. 学生闭环稳定后再进入PPO微调和部署验证。若冻结WM的学生表现不足，再据动作误差、视觉消融和地形分布决定是否补数据或低学习率联合微调；不在本次评估中改动参考WM网络。

当前教师仍是第一版扫描教师，学生结果应与其相同配置下的实际表现比较，不能将WM预训练结果当作教师或整套比赛障碍已经合格的证据。
