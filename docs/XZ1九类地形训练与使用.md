# XZ1 九类地形训练与使用

第四阶段教师完成后的采集入口、命令和质量统计见
[九类教师数据采集](XZ1九类教师数据采集-2026-10-28.md)。

扫描教师、深度采集和视觉学生使用九类地形，负责学习视觉越障。
独立 `Nazarite-HIM-Complex-Terrain-XZ1` 已恢复原七类基础运动地形及采样比例：
平地 10%、宽金字塔楼梯 15%、随机网格 25%、宽斜坡 10%、高墙 15%、
窄楼梯 15%、窄坡 10%。训练及 play 都使用这套基础地形。
下面的九类障碍、额外落地检查只作用于 WMP 教师及后续任务，配置独立复制。
任务名沿用现有注册项，不需要新增一组同功能任务。

## 地形与课程

| 类型 | 基础占比 | 最低 → 最高难度 |
| --- | --- | --- |
| flat 平地 | 10% | 平地练习，排除难度升降 |
| high_wall 高墙 | 10% | 高 0.05 → 0.30 m，厚 0.08 m |
| narrow_stairs 窄楼梯 | 15% | 三级、单级高 0.03 → 0.12 m；宽 0.80 m，踏步深 0.32 m，顶部平台 0.80 m，带下降段 |
| narrow_ramp 窄坡 | 10% | 高 0.06 → 0.36 m、坡度 10 → 20°；宽 0.80 m，实心梯形，顶部平台 0.80 m |
| plum_blossom 梅花桩 | 15% | 六根交错桩；边长 0.50 → 0.20 m，高 0.05 → 0.20 m；起终平台与桩顶等高 |
| single_beam 独木桥 | 15% | 单块桥长 3 m、宽 0.80 → 0.40 m，高 0.05 → 0.10 m；前后平台对齐 |
| low_frame 限高框架 | 10% | 内宽、长度 0.80 m；内部净高 0.60 → 0.29 m，四柱及四根顶部横梁 |
| tire_array 轮胎阵列 | 10% | 2×4，外径 0.55 m、内径 0.33 m、中心距 0.56 m；高度 0.03 → 0.165 m |
| gap 沟壑 | 5% | 连续三道，宽 0.02 → 0.36 m，深 0.15 → 0.36 m；中间平台长 0.80 m |

沿用 8×8 m 地块、10 行难度以及 DELTA 成败连续计数课程。
WMP 九类课程按参考 WMP 固定地形列，表中比例用于分配并行环境，不再每回合
重抽类型。每类在自己的环境内独立升降级，初始全部从第 0 行开始。
达到最高允许行后，再满足连续成功要求时，按原 WMP 从允许的所有行均匀随机
回采等级；当前为 0–9 行，各行均可抽到，包括最高行。类型不变，连续计数清零，
回采后重新积累成功／失败，避免长期只训练最高级而遗忘低中难度。
此行为由 `randomize_completed_levels=True` 开启，仅用于 WMP 九类课程；
独立七类 HIM 保留原课程。最高级失败仍按原规则降级，不会触发成功回采。
共享 DELTA 函数也按环境及类型分别保存等级、成功和失败计数；保留自适应抽样的
任务在换类型时读取该类型自己的进度，未访问类型从 0 级开始，避免课程状态串用。
新障碍参考本项目 Go2 WMP 的起步区—障碍—落地区设计；gap 参考原 WMP
连续沟壑，梅花桩与桥参考其稀疏支撑、平台布局，并适配 XZ1 和规则末级尺寸。
轮胎直接复用 Go2 WMP 分段环形碰撞生成函数，避免整圈网格被凸包填成实心。
难度按 mjlab 原生 0–1 行插值，最后一行确实达到最大难度。

保留平整出生区，不增加分道墙。非平地路线按世界 +x 前进，窄地形及新增五类
障碍使用已有中心线纠偏指令，速度 0.30–0.70 m/s。平地保持全向采样。
新障碍完成要求躯干超过末端 0.35 m、四脚都超过末端 0.05 m、至少两脚承重，
并且脚位于落地区。只走到第一道障碍、侧绕或踩坑底不会晋级。
梅花桩/独木桥有两脚承重落到周围低地时失败。
gap 改为脚与带专用名称的坑底碰撞几何体实际接触时失败；脚低于路面、
在平台侧壁产生竖直摩擦力不会再被当成踩坑底。按接触所属并行环境匹配，
覆盖全部 10 行地形，忽略未使用的接触槽和间距仍为正的接触。
与原足力检查一样，检查控制步最后一个物理子步，不累计所有子步的瞬时接触。
轮胎孔内接触地面允许，侧绕仍失败。新增 `obstacle_ground_contact` 终止指标。
高墙和限高框架不发默认站姿奖励，为跳跃、下蹲留出自由度；其他奖励权重沿用。

这是技能训练地形，并非完整比赛裁判：高墙仍贯通训练地块以阻止绕行；
梅花桩暂不验证“六根桩全部触及”；桥与轮胎的完整比赛判罚也尚未逐条实现。
轮胎为分段刚体近似，框架固定，不模拟轮胎形变或框架被撞移。

## 现有实现能否训练

可以运行现有教师 PPO → 新数据采集 → WM 预训练 → 深度学生蒸馏。
单帧本体观测 47 维、历史 6 帧、教师扫描 132 维、教师/学生 actor 输入 98 维、
critic 244 维，以及深度图 64×64、相机参数、WM 输入输出合同均保留。

旧扫描教师可通过 `initial-checkpoint` 仅迁移全部网络权重；优化器、迭代和课程
从新任务开始。原有盲 HIM 权重热启动入口也保留。旧七类课程不应直接 `resume`，
也不能将旧学生的播放表现作为新增五类障碍的通过率。学生恢复会检查地形类型合同。

限高框架是当前能力限制：向下扫描看到的是顶部横梁高度，不显式表示横梁下净空；
现有教师可先尝试学习，但没有保证能可靠教会视觉学生下蹲。若框架通过率停滞，
需要扩展教师的净空感知并重新训练，不能只增加学生蒸馏轮数。
同样，梅花桩、独木桥必须按类型和难度评测真实落脚与通过率。
XZ1 视觉学生目前仍是动作蒸馏，尚未实现后续视觉学生 PPO 微调阶段。

新教师训练通过后，要重新采集覆盖九类地形的数据，并在这些数据上训练 WM 与学生。
现有 WM 的 `--resume` 校验原数据 manifest，不能直接拿旧 WM 的 resume 参数换新数据。
当前先按已有入口启动一轮新的 WM 预训练；跨数据集仅加载 WM 权重的入口未提供。
旧数据和旧权重保留，作为对照基线。

## 现在先运行教师适应训练

在 `/home/haozi/桌面/Nazarite-mjlab/Train/Nazarite` 执行：

```bash
uv run --no-sync train Nazarite-WMP-HIM-Teacher-XZ1 \
  --env.scene.num-envs 800 \
  --agent.initial-checkpoint /home/haozi/桌面/Nazarite-mjlab/Train/Nazarite/logs/rsl_rl/xz1_wmp_him_teacher/2026-10-27_22-45-01_stage3_recycle_curriculum/model_1499.pt \
  --agent.max-iterations 1500 \
  --agent.run-name stage4_gap_contact
```

默认初始难度为第 0 行。这是从现有教师继续学习：加载全部网络权重，重新建立
优化器、迭代计数和课程。gap 失败判定修正后课程合同升级为 v4，只使用
`initial-checkpoint` 权重热启动，不对旧 v2/v3 课程使用 `resume`。
最高级成功后随机回采允许行的策略保留，独立七类 HIM 不变。
建议 100–200 次检查日志，300–500 次检查固定难度 play／独立评测；
1500 是新增训练预算，不是旧训练累计轮数，也不是收敛保证。
重点复查 gap 第 1 级、低难度梅花桩、最高高墙的固定慢速和中间难度轮胎，
同时防止独木桥、窄坡与框架退化。
回采使平均等级下降属于预期，判断是否改善应看各级实际回合数和通过率。
重点查看各类型成功率/难度、`left_narrow_course`、`obstacle_ground_contact`、
`base_contact`、`fell_over` 以及速度误差；总奖励、平均地形等级不足以证明越障能力。

TensorBoard 新增 `Terrain/<类型>/level_<等级>/episodes`、`success_rate`、
`timeout_rate`、`numerical_failure_rate`，以及 `Terrain/<类型>/all/*` 汇总。
它们按结束回合的原类型和等级累计计数；没有样本时只记录 episodes=0，不伪造 0% 成功率。
成功要求有效越过路线终点且无失败终止、姿态在 45° 内；窄路线沿用四脚落地检查，
高墙要求越过远端及裕量，平地用 2.4m 位移作为完成定义。此统计不等于完整比赛裁判。
`timeout_rate` 只统计真正耗尽时间且未通过的回合，不把成功结束赛道的 time_out 标记计入。
保存 checkpoint 时同步写 `terrain_outcomes.json`，可查看每类每级的原始整数计数。

若触发非有限恢复，日志目录下的 `numerics/recovery_*.pt` 保存类型、等级、
出生原点、根位姿和速度、关节名/位置/速度、原始 qpos/qvel/qacc、动作、接触几何体
ID/名称/位置/间距及观测证据。自动 reset 的终端现场会先缓存，避免记录到新回合状态；
现场写入失败会警告，但保留原恢复流程。碰撞几何和求解器参数保持原配置。

下面命令评测当前教师在修正判定下的九类、全部 10 级基线。
新教师训练后替换 checkpoint 路径和 output 文件名，保持其余参数一致比较：

```bash
uv run --no-sync python -m nazarite.scripts.evaluate_xz1_wmp \
  --policy teacher \
  --checkpoint /home/haozi/桌面/Nazarite-mjlab/Train/Nazarite/logs/rsl_rl/xz1_wmp_him_teacher/2026-10-27_22-45-01_stage3_recycle_curriculum/model_1499.pt \
  --all-levels \
  --episodes 16 --num-envs 16 \
  --seed 43 --speed 0.4 --command-mode course \
  --reset-x 0.1 --reset-y 0.05 --reset-yaw 0.05 \
  --output /tmp/xz1_stage3_v4_all_levels.json
```

评测、采集的默认地形列表都覆盖九类。`velocity` 不使用中心线真值纠偏；
`course` 可单独检查与训练一致的纠偏条件，两者应分别报告，避免高估部署能力。
`--all-levels` 覆盖训练行 0–9，难度依次为 `行号/9`；也可用
`--levels 0 1 5 9` 指定行，或沿用 `--difficulties 0 0.5 1`。
三种入口互斥。每个地形/等级/种子/速度组合单独分配 `episodes` 个回合，
全部组合的总数为这些轴数量的乘积，不会只采样最先结束的若干回合。
每个并行环境预先分配近似相等的回合配额；完成配额的环境继续 reset 以保持
仿真有效，但不再计入成绩。JSON 记录 `episode_quotas`、`env_id`、
`episode_index` 和 `sampling=per_environment_quota_v1`，便于核对样本完整性。
历史采用先结束先计入的评测可能有偏差，应使用新评测器重跑基线再比较。

## 验证范围

检查包含低/中/高难度地形编译、出生支撑、实体轮胎孔洞和沟壑射线检查、
生成/评测/运行时边界一致性，以及绕行、部分跨越、违规低地落脚判断。
另在 GPU 上强制安排九类地形的最低/最高难度共 18 个环境，验证旧教师权重加载、
一次 PPO 更新、真实深度图和旧视觉学生的推理接口。短测只证明运行兼容，
未开展正式长训，也未证明新增障碍的训练通过率。
